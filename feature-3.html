Security Control List

  • 🛡️ Credential Isolation: AWS keys remain on server. Never exposed to browser scripts.
  • 🔑 Pre-Signed PUT: Granular, short-lived signatures valid for exactly 15 minutes.
  • 🔀 File Overwrite Protection: Automatic secure random prefix token hashing prevents overwrites.
  • ⚠️ MIME Type Integrity: Content-Type is bound inside the signature to prevent MIME sniffing.
